# Proposal: 冰淇淋物價大盤指數觀測站 (HW4_inflation)

## 背景
冰淇淋價格是日常生活中最貼近民眾的物價指標之一。透過追蹤冰淇淋的歷史價格變化，我們可以直觀地感受到通貨膨脹的影響。

## 目標
建立一個簡易的 Web 應用程式「冰淇淋物價大盤指數觀測站」，讓使用者能夠新增與查詢不同日期的冰淇淋價格，進而追蹤物價上漲的趨勢。

## 預期功能與亮點
1. **輸入表單**：提供使用者輸入資料的介面，包含三個欄位：日期 (Date)、商品名稱 (Item Name，例：麥當勞蛋捲冰淇淋)、價格 (Price)。
2. **查詢清單與「趨勢指標」**：以表格 (Table) 的形式呈現所有歷史物價紀錄。特別加入「趨勢」欄位，系統會自動比對同一項商品前一次的價格，若呈現上漲，將以醒目的紅色向上箭頭 (↑ 漲價) 標示，讓通膨趨勢一目了然。
3. **即時搜尋過濾 (Real-time Filtering)**：提供文字搜尋框，使用者打字輸入關鍵字的當下，即時過濾並動態更新下方的表格內容，無須點擊按鈕或重新整理網頁，提供極致流暢的 UX。

## 4. 技術架構與資料範圍
1. 本專案前端使用 Vanilla JavaScript (不依賴任何框架) 搭配 fetch API，後端使用 Node.js + Express.js，並採用純手寫 SQL 語法操作 SQLite 資料庫，確保底層技術的扎實度。
2. 本專案初期將預先載入「麥當勞蛋捲冰淇淋」與「全家 Fami!ce 霜淇淋」的歷史價格作為展示用種子資料。
